Article Weights from Safety Data Sheets
● Production · Live

The warehouse no longer has to weigh every product. This tool computes article weight from density × volume + tare, where the density comes from the safety and product information sheets that the KING ERP already links to per article. For 7,382 articles without a weight, with a built-in self-check that cannot silently pass.

7,382Articles without weight
98%Coverage from data sheets
8.6%Median error (blind test)
27Regression tests
  • KING points to the sheet itself: the free fields hold the full path to the PDF sheet, so extraction runs without unreliable matching on product name
  • Two tracks: density from the SDS for single packs, from the product sheet for two-component sets (69% of stock) where the mixed product is what counts
  • A self-check that doesn't fool itself: reconciles against already-weighed articles and fails visibly when the calibration set is too small to prove anything
  • Unknown is never 0: without a density an article goes to the manual list — a silent zero would send a Euro pallet out the door at parcel rate

Dynamic Shipping-Cost Engine
● Production · Live

Replaces the flat €22.50 rate with a weight matrix that determines the right class, carrier and price per order — for fov.nl and the German webshop. All rates live in configuration, not in code, and 46 tests guard exactly the edge cases where a shipping calculation quietly leaks money.

46Edge-case tests
2Countries (NL + DE)
5Weight classes
  • Weight matrix instead of a flat rate: five classes from parcel to Euro pallet, with a free-shipping threshold, identical for NL and DE
  • Rates in JSON, not in code: a rate change is a config change — no release needed
  • Multiple carriers per order: splits a German order across DHL and Veenstra Fritom and shows per shipment what actually leaves
  • Unknown weight is never zero: if one weight is missing, the result is explicitly "undeterminable" instead of a too-low price on the freight invoice

Portfolio Monitor — open source on GitHub
▶ Try the live demo → github.com/bastiaanvdh/portfolio-monitor

A 19-agent Python pipeline that analyzes my full portfolio daily: prices, alerts, earnings, peer comparison, macro correlations and scenario analysis. No external subscription, no AI API — everything runs locally and serves an interactive Chart.js dashboard on localhost. The watchlist screener automatically vets candidate stocks using a vault-code methodology (score 0–100), including fair-value calculation and entry criteria check. Published open source so others can set it up with their own positions.

  • Daily briefing: Price movements, macro data (EUR/USD, VIX, S&P 500), alerts and news per position — generated as HTML in seconds
  • Thesis thermometer: Each position has a documented investment thesis with weighted fundamental checks — score 0–100, tracked daily
  • Macro correlation + scenarios: Pearson correlation matrix with numpy OLS betas, followed by 5 macro shock scenarios (recession, dollar rally, inflation etc.)
  • Watchlist screener: Candidate stocks are automatically screened on fundamentals, valuation and peers — with entry criteria check per name
  • EUR/USD exposure: Exact currency splits and sensitivity table for purchasing power risk as a Dutch investor with a predominantly USD portfolio
