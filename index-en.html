Portfolio Monitor — open source on GitHub
→ github.com/bastiaanvdh/portfolio-monitor

A 19-agent Python pipeline that analyzes my full portfolio daily: prices, alerts, earnings, peer comparison, macro correlations and scenario analysis. No subscription, no AI API — everything runs locally and serves an interactive Chart.js dashboard. The watchlist screener automatically evaluates candidate stocks using a structured methodology (score 0–100), including fair-value calculation and entry-criteria check. Open sourced so others can set it up with their own positions.

  • Daily briefing: Price movements, macro data (EUR/USD, VIX, S&P 500), alerts and news per position — generated as HTML in seconds
  • Thesis thermometer: Every position has a documented investment thesis with weighted fundamental checks — score 0–100, updated daily
  • Macro correlation + scenarios: Pearson correlation matrix with numpy OLS betas, followed by 5 macro shock scenarios (recession, dollar rally, inflation etc.)
  • Watchlist screener: Candidate stocks automatically analyzed on fundamentals, valuation and peers — with entry-criteria check per name
  • EUR/USD exposure: Exact currency splits and sensitivity table for purchasing power risk as a Dutch investor with a predominantly USD portfolio
